## 5. Vyhľadávacie kľúče (rýchlo)

**Hľadanie modelu:**
```bash
grep "RAS-B13P2KVSG-E" single_split.json multi_split.json accessories.json
```

**JSON štruktúra (všetky súbory):**
- Každý JSON má **metadata** + tematické sekcie
- Ceny v `set_price_EUR` / `indoor_price_EUR` / `outdoor_price_EUR` / `price_EUR`
- Vnútorná = `indoor`, Vonkajšia = `outdoor`

**Konvencia model code (Toshiba RAS):**
- `RAS-B**` – vnútorná nástenná (Single + Multi)
- `RAS-M**` – multi-only vnútorná (kazeta/kanál + niektoré nástenné veľkosti 05)
- `RAS-**` (bez B/M prefixu) – Single-Split vonkajšia
- `RAS-#M**G3AVG-E` – Multi-Split vonkajšia (#=2,3,4,5 = počet izieb)
- `RB-` – ovládače / WiFi / textilné kryty
- `RBC-` – ovládače / panely pre kazety
- `TCB-` – externé moduly, snímače, BMS
- Sufixy:
  - `B2KVG` – SEIYA Classic 2
  - `E2KVG` – SEIYA
  - `P2KVSG` / `P2KVSGB` – SHORAI CURVE White / Black
  - `N4KVRG` – HAORI
  - `S4KVPG` / `S4KVDG` – DAISEIKAI 10 White / Wood
  - `J2FVG` – Parapetná
  - `G3YVG` – 1-cestná FLAT kazeta
  - `S4MUVG` – 60x60 Slim kazeta
  - `U2DVG` – Kanálová

## 6. Token-efektívna stratégia pre chatbota

| Stratégia | Tokeny / dotaz | Vhodné pre |
|---|---|---|
| **A. TOSHIBA_INDEX.md v system prompte** + 3 JSON ako tools | ~3,5k base + 1-3k per query | **odporúčané** |
| **B. Všetko v system prompte** (single + multi + acc.) | ~25k cached + ~500 fresh | málo konverzácií |
| **C. RAG (embeddings + retrieval)** | ~200-700 / dotaz | tisíce konverzácií |

**Odporúčaný setup:** systém prompt obsahuje TOSHIBA_INDEX.md + [glossary.json](glossary.json) (~5k tokenov), bot má tooly:
- `get_single_split_series(series_name)` → vráti príslušnú radu z [single_split.json](single_split.json)
- `get_multi_split_combination(outdoor_model)` → vráti povolené vnútorné z [multi_split.json](multi_split.json)
- `get_accessory(code_or_purpose)` → vyhľadá v [accessories.json](accessories.json)

**Glossary tip:** [glossary.json](glossary.json) sa hodí načítať vždy do system promptu (~2k tokenov) – obsahuje:
- `product_type_aliases` a `series_aliases` – pre rozpoznanie EN/hovorových výrazov ("wall-mounted" → "Nástenná", "shorai cierny" → "SHORAI CURVE Black")
- `feature_aliases` – synonymá pre WiFi, plazma, A+++, atď.
- `technical_glossary` – definície SEER/SCOP/HADA careflow/Bi-Flow pre vysvetlenia zákazníkovi
- `use_case_to_recommendation` – mapovanie použitia (spálňa 25 m², alergici, tichý režim) na konkrétne modely
- `common_questions_and_answers` – FAQ pre rýchle odpovede
