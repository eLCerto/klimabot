## 6. Predajný cheat-sheet

### Pre koho je RAV vhodný?
- **Obchody, kancelárie, malé komerčné priestory** – stredne veľké inštalácie
- **Priestory so servermi** – špeciálne funkcie zálohovania/striedania, voľné chladenie
- **Viac zón jedným typom** – Twin/Triple/Double-Twin kity (jedna zóna, zdieľaný okruh — nie záloha pre serverovňu)
- **Integrácia do BMS** – BACnet, Modbus, KNX, TCC-Link
- **Veľké inštalácie s dlhým potrubím** – DI BIG do 100 m

### Voľba outdoor línie podľa potreby

## 7. Vyhľadávacie kľúče

**Hľadanie modelu:**
```bash
grep "RAV-HM561CTP-E" outdoor.json indoor.json accessories.json
```

**JSON štruktúra:**
- `outdoor.json` → 4 outdoor lines, multi_kits_compatibility
- `indoor.json` → 11 indoor types s `set_prices_*` per outdoor line
- `accessories.json` → ovládače, panely, snímače, BMS, externé moduly, kity

**Konvencia model code (Toshiba RAV):**
- **Vonkajšie:**
  - `RAV-G**`: 
    - `GV` = DI CLASSIC
    - `GM` = DI (alebo DI BIG ak `GM2243/2803`)
    - `GP` = SDI
  - Suffix `T` = 1f, `T8` = 3f
  - Číslo (561, 801…) = veľkosť (kW × 10 zhruba)

- **Vnútorné:**
  - `RAV-HM__KRTP-E` = nástenná
  - `RAV-HM__CTP-E` = podstropná
  - `RAV-HM__MUTP-E` = 60x60 Slim kazeta
  - `RAV-HM__UT-E` = Smart kazeta (bez P na konci)
  - `RAV-HM__UTP-E` = 4-cestná štandardná kazeta
  - `RAV-HM__U1TP-E` = 1-cestná FLAT kazeta
  - `RAV-HM__SDTY-E` = plochá kanálová
  - `RAV-HM__BTP-E` = štandardná kanálová
  - `RAV-RM__DTP-E2` = vysokotlaková kanálová (DI BIG)
  - `RAV-HM__FT-E` = stojanová

- **Príslušenstvo:**
  - `RBC-` = ovládače / panely
  - `TCB-` = externé moduly, snímače, čerpadlá, príruby
  - `BMS-` = WiFi rozhrania
  - `TO-RC-` = BMS (KNX, Modbus, BACnet)
  - `MWR-` = (sa nepoužíva v RAV, len v RAS/Samsung)

## 8. Token-efektívna stratégia

| Stratégia | Tokeny / dotaz | Vhodné pre |
|---|---|---|
| **A. RAV_INDEX.md v system prompte** + 3 JSON ako tools | ~6k base + 2-4k per query | **odporúčané** |
| **B. Všetko v system prompte** | ~35k cached + ~500 fresh | málo konverzácií |
| **C. RAG (embeddings + retrieval)** | ~300-800 / dotaz | tisíce konverzácií |

**Odporúčaný setup:** systém prompt obsahuje RAV_INDEX.md + [glossary.json](glossary.json) (~8k tokenov), bot má tooly:
- `get_outdoor_line(line)` → vráti DI-C / DI / SDI / DI BIG sekciu z [outdoor.json](outdoor.json)
- `get_indoor_type(type)` → vráti príslušný typ vnútornej z [indoor.json](indoor.json)
- `get_accessory(code_or_purpose)` → vyhľadá v [accessories.json](accessories.json)
- `get_set_price(indoor_type, size, outdoor_line, phase)` → vráti cenu setu z [indoor.json](indoor.json) sekcie `set_prices_*`

**Glossary tip:** [glossary.json](glossary.json) treba načítať do system promptu (~2,5k tokenov) – obsahuje:
- `outdoor_line_aliases` – rozpozná „digital inverter", „big single fan" atď.
- `indoor_type_aliases` – rozpozná „ducted", „high pressure duct", „smart cassette"
